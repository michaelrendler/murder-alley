# Murder Alley

A static website for Murder Alley — an immersive storytelling experience in Los Angeles.

## Design

CSS styling inspired by [dataland.art](https://dataland.art/):

- Dark, immersive aesthetic with black backgrounds and white typography
- Light-weight display font (Outfit) with monospace accents (Space Mono)
- Full-viewport hero section
- Pill-shaped CTA buttons with orange accent color
- Scrolling marquee ticker
- Responsive layout with mobile hamburger menu
- White footer with black text for contrast

## Running locally

Open `index.html` in a browser. No build step required.
